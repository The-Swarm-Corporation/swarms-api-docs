## Connecting to the API

All requests go to a single base URL regardless of where you connect from:

```
https://api.swarms.world
```

There is no region-specific hostname or path — use this base URL for every request, from any location.

```bash
curl -H "x-api-key: $SWARMS_API_KEY" \
     https://api.swarms.world/health
```

## What This Means for Your Integration

- **No configuration needed**: Point your client at `https://api.swarms.world` — there is nothing region-specific to select or configure.
- **Standard HTTP networking applies**: Latency to `https://api.swarms.world` depends on your own network path and DNS resolution, like any other HTTPS API.
- **Retries and timeouts**: Treat the API like any internet-hosted HTTPS service — implement normal timeout and retry handling (see [Rate Limit Headers](/docs/documentation/resources/rate-limit-headers) for `Retry-After` on 429s).

## If You Need Region or Residency Guarantees

If your use case requires guarantees about where requests are processed or data is stored, contact [technical support](/docs/documentation/resources/technical-support) or your account team directly rather than relying on this page — those details are outside what the public API surface exposes.
