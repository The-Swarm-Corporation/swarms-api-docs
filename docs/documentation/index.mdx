## API Endpoint Overview

Base URL: `https://api.swarms.world`. All endpoints except `/` and `/health` require the `x-api-key` header (`Authorization: Bearer <key>` is also accepted). Endpoints marked Premium require a Pro, Ultra, or Premium subscription; call `GET /v1/account/premium-endpoints` for the live list.

| Method | Endpoint | Premium | Description |
|--------|----------|---------|-------------|
| GET | `/` | No | API root / welcome message |
| GET | `/health` | No | Health check |
| POST | `/v1/agent/completions` | No | Single agent completion |
| POST | `/v1/agent/batch/completions` | Yes | Batch agent completions (up to 50 per request) |
| POST | `/v1/swarm/completions` | No | Multi-agent swarm completion |
| POST | `/v1/swarm/batch/completions` | Yes | Batch swarm completions |
| POST | `/v1/chat/completions` | No | OpenAI-compatible chat completions |
| GET | `/v1/models` | No | OpenAI-compatible model list |
| GET | `/v1/models/available` | No | Available models with metadata |
| POST | `/v1/reasoning-agent/completions` | Yes | Reasoning agent completion |
| GET | `/v1/reasoning-agent/types` | No | List available reasoning agent types |
| GET | `/v1/swarms/available` | No | List swarm types and their metadata |
| GET | `/v1/account/logs` | No | API request logs for your account |
| GET | `/v1/account/metrics/summary` | No | Usage metrics summary |
| GET | `/v1/account/premium-endpoints` | No | List endpoints that require Premium |
| GET | `/v1/account/credits` | No | Credit balance |
| GET | `/v1/agents/list` | No | List your saved agent configurations |
| GET | `/v1/rate/limits` | No | Current rate limit status and usage |
| GET | `/v1/tools/available` | No | List built-in tools (`auto_search`, `web_scraper`) |
| GET | `/v1/usage/costs` | No | Full pricing details |
| POST | `/v1/batched-grid-workflow/completions` | Yes | Batched grid workflow (agents x tasks) |
| POST | `/v1/graph-workflow/completions` | Yes | Directed-graph multi-agent workflow |
| POST | `/v1/auto-agent-builder/completions` | No | Generate an agent roster for a task (does not execute it) |
