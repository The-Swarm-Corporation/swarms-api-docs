---
title: 'Get Credit Balance'
description: 'Retrieve your API credit balance. Only purchased credit pays for API usage; free and referral credits are shown but never spent'
---



Retrieve your current API credit balance from the `/v1/account/credits` endpoint. It returns every credit type on your account: purchased credits, free credits and referral credits, plus `total_credits`, the spendable balance, which equals `credit`.

<Info>
Credits are automatically deducted after each API request completes, from `credit` (purchased) only. `free_credit` and `referral_credits` are never spent. Check your balance regularly and top up at [cloud.swarms.world/settings](https://cloud.swarms.world/settings).
</Info>

## Response Schema

### CreditBalanceOutput Object

| Field | Type | Description |
|-------|------|-------------|
| `credit` | `number` | Purchased credit balance. The only balance that pays for API usage |
| `free_credit` | `number` | Free credit balance (promotional or welcome credits). Shown for reference only; never spent |
| `referral_credits` | `number` | Credits earned through the referral program. Shown for reference only; never spent |
| `total_credits` | `number` | Spendable balance, equal to `credit`. This is the balance checked against the \$1.00 minimum |

### Example Response

```json
{
  "credit": 50.00,
  "free_credit": 20.00,
  "referral_credits": 5.00,
  "total_credits": 50.00
}
```

## Credit Usage Order

Only purchased credit (`credit`) pays for API usage. Each charge is deducted from `credit`; `free_credit` and `referral_credits` are still returned by this endpoint but are never spent.

A charge larger than your purchased balance fails with `402 Payment Required`:

```text
Insufficient credits. Only purchased credits pay for API usage; free and referral credits are no longer accepted. Top up your credits at https://cloud.swarms.world/settings to continue using the API.
```

<Note>
Separately from the per-request charge check above, billable endpoints (`/v1/swarm/completions`, `/v1/chat/completions`, `/v1/agent/completions`, `/v1/agent/batch/completions`, and the other completion routes) require a **purchased credit balance greater than \$1.00** (`credit`, the same number as `total_credits`) before the request is even accepted. At or below \$1.00 they return `402` with `error.type` `insufficient_credits` and `error.upgrade_url` `https://cloud.swarms.world/settings`, even if the account holds free or referral credits. This is a pre-flight guard in the API key middleware, independent of what the specific request ends up costing.
</Note>

## Use Cases

### Monitor Credit Balance

Check your credit balance before running large batch operations:

```python
def check_balance_before_batch():
    balance = get_credit_balance()
    if balance and balance['total_credits'] < 10.00:
        print("⚠️ Low credit balance. Consider adding credits before running batch operations.")
        return False
    return True

if check_balance_before_batch():
    # Run batch operations
    pass
```

### Track Credit Consumption

Monitor credit usage over time:

```python
import time
from datetime import datetime

def track_credits(duration_minutes=60, interval_seconds=300):
    """Track credit balance over time."""
    end_time = time.time() + (duration_minutes * 60)
    
    while time.time() < end_time:
        balance = get_credit_balance()
        if balance:
            timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
            print(f"[{timestamp}] Total Credits: ${balance['total_credits']:.2f}")
        
        time.sleep(interval_seconds)
```

## Best Practices

1. **Regular Monitoring**: Check your credit balance regularly, especially before large operations
2. **Low Balance Alerts**: Set up alerts when credits fall below a threshold
3. **Credit Types**: Only `credit` (purchased) pays for API usage; free and referral credits don't, so watch `credit` or `total_credits`
4. **Top Up**: Buy credits at [cloud.swarms.world/settings](https://cloud.swarms.world/settings)
