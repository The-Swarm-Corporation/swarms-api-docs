Get a comprehensive list of all AI models available through the Swarms API. This endpoint provides information about supported models from various providers including OpenAI, Anthropic, Groq, and others.

<Info>
The `/v1/models/available` endpoint returns all models currently supported by the Swarms API, each with its price per 1M input and output tokens (15% service fee included).
</Info>

## Quick Start

<Tabs>
  <Tab title="Python">
    ```python
    import requests
    import json
    import os
    from dotenv import load_dotenv

    load_dotenv()

    API_KEY = os.getenv("SWARMS_API_KEY")
    BASE_URL = "https://api.swarms.world"

    headers = {
        "x-api-key": API_KEY,
        "Content-Type": "application/json"
    }

    def get_available_models():
        """Get all available models"""
        response = requests.get(
            f"{BASE_URL}/v1/models/available",
            headers=headers
        )

        if response.status_code == 200:
            return response.json()
        else:
            print(f"Error: {response.status_code} - {response.text}")
            return None

    # Get available models
    models_data = get_available_models()
    if models_data:
        print("✅ Available models retrieved successfully!")
        print(f"Model count: {models_data['count']}")
        for model in models_data["models"][:5]:
            print(
                f"{model['model_name']}: ${model['input_cost_per_1m']} input, "
                f"${model['output_cost_per_1m']} output per 1M tokens"
            )
    ```

## Understanding the Response

The models endpoint returns every model available to your subscription tier, each with its price per 1M tokens. Prices below are examples at the time of writing (truncated to a few models); call the endpoint for current prices:

```json
{
  "success": true,
  "count": 1894,
  "models": [
    {
      "model_name": "gpt-5.4",
      "input_cost_per_1m": 2.875,
      "output_cost_per_1m": 17.25,
      "price_source": "litellm"
    },
    {
      "model_name": "gpt-4.1",
      "input_cost_per_1m": 2.3,
      "output_cost_per_1m": 9.2,
      "price_source": "litellm"
    },
    {
      "model_name": "claude-sonnet-5",
      "input_cost_per_1m": 2.3,
      "output_cost_per_1m": 11.5,
      "price_source": "litellm"
    },
    {
      "model_name": "claude-haiku-4-5",
      "input_cost_per_1m": 1.15,
      "output_cost_per_1m": 5.75,
      "price_source": "litellm"
    },
    {
      "model_name": "openrouter/moonshotai/kimi-k3",
      "input_cost_per_1m": 0.8395,
      "output_cost_per_1m": 11.5,
      "price_source": "openrouter"
    }
  ]
}
```

| Field | Type | Description |
|-------|------|--------------|
| `success` | boolean | Whether the request succeeded |
| `count` | integer | Number of models in the `models` list |
| `models` | array of objects | Every available model with its price, filtered by your subscription tier (free tier accounts won't see premium or Groq models) |

Each entry in `models` has these fields:

| Field | Type | Description |
|-------|------|--------------|
| `model_name` | string | The model identifier to pass as `model_name` |
| `input_cost_per_1m` | number | Price per 1M input tokens (USD), including the 15% service fee |
| `output_cost_per_1m` | number | Price per 1M output tokens (USD), including the 15% service fee |
| `price_source` | string | Where the price came from: `openrouter` for `openrouter/...` models, `litellm` for the rest, or `fallback` when there is no price data for the model |

<Warning>
`models` used to be a list of strings. It is now a list of objects, so read each name from `model_name`: use `[m["model_name"] for m in data["models"]]` instead of `data["models"]`, and `"gpt-5.4" in {m["model_name"] for m in data["models"]}` for membership checks.
</Warning>

By default, this list also includes models fetched live from OpenRouter (cached for 5 minutes) and prefixed with `openrouter/` (e.g. `openrouter/aion-labs/aion-3.0`). The base catalog is precomputed and cached server-side, so this endpoint is cheap to call.

## Pricing for One Model

To look up a single model's price, call `GET /v1/models/pricing` with the model name as the `model_name` query parameter. Any model name gets a price, listed or not:

<Tabs>
  <Tab title="Python">
    ```python
    response = requests.get(
        f"{BASE_URL}/v1/models/pricing",
        headers=headers,
        params={"model_name": "gpt-5.4"},
    )
    price = response.json()
    print(
        f"{price['model_name']}: ${price['input_cost_per_1m']} input, "
        f"${price['output_cost_per_1m']} output per 1M tokens ({price['price_source']})"
    )
    ```
  </Tab>
  <Tab title="cURL">
    ```bash
    curl -G "https://api.swarms.world/v1/models/pricing" \
      --data-urlencode "model_name=gpt-5.4" \
      -H "x-api-key: $SWARMS_API_KEY"
    ```
  </Tab>
</Tabs>

Example response (prices at the time of writing, 15% service fee included):

```json
{
  "status": "success",
  "model_name": "gpt-5.4",
  "input_cost_per_1m": 2.875,
  "output_cost_per_1m": 17.25,
  "price_source": "litellm",
  "timestamp": "2026-10-12T19:01:46.491705+00:00"
}
```

`price_source: "fallback"` means there is no price data for that model name. A run on it is billed at the fallback rates of \$6.50 per 1M input and \$18.50 per 1M output tokens before the fee, so the endpoint returns \$7.475 and \$21.275 for it. See [Pricing](/docs/documentation/resources/pricing) for how token costs and flat fees add up.

See the [OpenAI-Compatible Endpoint](/docs/documentation/capabilities/openai-compatible) reference for using these models with the OpenAI SDK.

## Dynamic Model Selection

<Tabs>
  <Tab title="Python">
    ```python
    def select_best_model(task_type, priority="balanced"):
        """
        Dynamically select the best model based on task type and priority

        Args:
            task_type: Type of task ("creative", "analytical", "fast", "vision")
            priority: Priority ("quality", "speed", "cost", "balanced")
        """
        # Get available models first
        models_data = get_available_models()
        if not models_data or not models_data.get("success"):
            return "gpt-4.1-mini"  # Fallback

        available_models = {m["model_name"] for m in models_data.get("models", [])}

        # Model selection logic
        if task_type == "creative":
            if priority == "quality":
                return "gpt-4.1" if "gpt-4.1" in available_models else "claude-sonnet-5"
            elif priority == "speed":
                return "gpt-4.1-mini" if "gpt-4.1-mini" in available_models else "claude-haiku-4-5"
            else:  # balanced
                return "gpt-4.1-mini"

        elif task_type == "analytical":
            return "gpt-4.1" if "gpt-4.1" in available_models else "claude-sonnet-5"

        elif task_type == "fast":
            return "gpt-4.1-mini" if "gpt-4.1-mini" in available_models else "groq/openai/gpt-oss-20b"

        elif task_type == "vision":
            return "gpt-4.1" if "gpt-4.1" in available_models else "gpt-4-turbo"

        return "gpt-4.1-mini"  # Default fallback

    # Example usage
    best_model = select_best_model("creative", "quality")
    print(f"Selected model: {best_model}")
    ```

## Error Handling

<Tabs>
  <Tab title="Python">
    ```python
    def get_available_models_with_fallback():
        """Get available models with proper error handling"""
        try:
            response = requests.get(
                f"{BASE_URL}/v1/models/available",
                headers=headers,
                timeout=10
            )

            if response.status_code == 200:
                data = response.json()
                if data.get("success"):
                    return data.get("models", [])
                else:
                    print("❌ API returned success=false")
                    return []
            elif response.status_code == 401:
                print("❌ Authentication failed. Check your API key.")
                return []
            elif response.status_code == 429:
                print("❌ Rate limit exceeded. Please wait before retrying.")
                return []
            else:
                print(f"❌ HTTP {response.status_code}: {response.text}")
                return []

        except requests.exceptions.Timeout:
            print("❌ Request timed out")
            return []
        except requests.exceptions.ConnectionError:
            print("❌ Connection error")
            return []
        except Exception as e:
            print(f"❌ Unexpected error: {e}")
            return []

    # Use with fallback
    models = get_available_models_with_fallback()
    if models:
        print(f"Available models: {len(models)}")
    ```
  </Tab>
  <Tab title="JavaScript">
    ```javascript
    async function getAvailableModelsWithFallback() {
        try {
            const controller = new AbortController();
            const timeoutId = setTimeout(() => controller.abort(), 10000);

            const response = await fetch(`${BASE_URL}/v1/models/available`, {
                method: 'GET',
                headers: headers,
                signal: controller.signal
            });

            clearTimeout(timeoutId);

            if (!response.ok) {
                if (response.status === 401) {
                    console.log("❌ Authentication failed. Check your API key.");
                } else if (response.status === 429) {
                    console.log("❌ Rate limit exceeded. Please wait before retrying.");
                } else {
                    console.log(`❌ HTTP ${response.status}: ${await response.text()}`);
                }
                return [];
            }

            const data = await response.json();

            if (!data.success) {
                console.log("❌ API returned success=false");
                return [];
            }

            return data.models || [];

        } catch (error) {
            if (error.name === 'AbortError') {
                console.log("❌ Request timed out");
            } else if (error.name === 'TypeError') {
                console.log("❌ Connection error");
            } else {
                console.log(`❌ Unexpected error: ${error.message}`);
            }
            return [];
        }
    }

    // Use with fallback
    getAvailableModelsWithFallback().then(models => {
        if (models.length > 0) {
            console.log(`Available models: ${models.length}`);
        }
    });
    ```

## Best Practices

1. **Cache Results**: Cache the models list to avoid frequent API calls
2. **Handle Changes**: Models may be added or removed over time
3. **Fallback Logic**: Always have fallback models for reliability
4. **Version Awareness**: Be aware of model versioning and deprecation
5. **Cost Monitoring**: Track usage costs for different models; each model has its own price per 1M tokens
6. **Performance Testing**: Test model performance for your specific use cases
7. **Documentation Review**: Check model-specific limitations and capabilities
