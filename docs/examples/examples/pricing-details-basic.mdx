---
title: 'Get Comprehensive Pricing Details'
description: 'Fetch and inspect comprehensive pricing details for all Swarms API features'
---



Retrieve the flat fees and discounts that apply across the Swarms API from the `/v1/usage/costs` endpoint: the per-agent fee, the image and search fees, the night-time discount, and the fallback token rates used only for models with no price data.

Token prices are **per model**: each model's tokens are billed at its provider price plus a 15% service fee. Look a model up with `GET /v1/models/pricing` (see [Token Prices per Model](#token-prices-per-model) below). MCP servers and the `web_scraper` tool add no fee; only the tokens they use are billed.

<Info>
The pricing endpoint is **read-only** and safe to call in automation. Always treat returned values as dynamic and avoid hard-coding pricing in production systems.
</Info>

## Response Shape

The endpoint returns a `usage_pricing` object plus a `timestamp`:

```json
{
  "usage_pricing": {
    "fallback_input_cost_per_1m": 6.5,
    "fallback_output_cost_per_1m": 18.5,
    "swarm_completions_agent_cost": 0.01,
    "agent_completions_img_cost": 0.25,
    "search_cost": 0.04,
    "night_time_discount": 0.5
  },
  "timestamp": "2026-10-12T19:01:46.180153+00:00"
}
```

| Field | Meaning |
|---|---|
| `fallback_input_cost_per_1m` | Input price per 1M tokens for a model with **no price data**, before the 15% service fee (\$7.475 after it). Priced models are billed at their own rate, not this one. |
| `fallback_output_cost_per_1m` | Output price per 1M tokens for a model with no price data, before the service fee (\$21.275 after it). |
| `swarm_completions_agent_cost` | Fee per agent in the request, for swarm completions, graph workflows and batched grid workflows. |
| `agent_completions_img_cost` | Fee per image on agent completions, counted across `img` and `imgs`. |
| `search_cost` | Charged once per agent completion request that enables `auto_search` in `tools_enabled`, however many searches the agent runs, including none. |
| `night_time_discount` | Multiplier on the token cost of swarm completions (including streaming and batch) from 8 PM to 6 AM Pacific, for paid plans only: tier `pro`, `ultra` or `premium`, or an active subscription. The field is the same for every account, but a free account pays the full token price at any hour. The per-agent fee is not discounted. |

<Warning>
The flat token-rate fields (`swarm_completions_input_cost_per_1m`, `swarm_completions_output_cost_per_1m`, `agent_completions_input_cost_per_1m`, `agent_completions_output_cost_per_1m`) and the MCP and scrape fees (`agent_completions_mcp_cost`, `scrape_cost`) have been removed from this response. Code that reads them needs updating: get token prices per model, as shown below.
</Warning>

<Note>
`GET /v1/usage/costs` is not yet exposed as a dedicated method on the `swarms-client` SDK (0.8.0) — use `requests` or `fetch` directly, as above.
</Note>

## Token Prices per Model

`GET /v1/models/pricing` returns one model's price per 1M tokens, with the 15% service fee already included:

```bash
curl -G "https://api.swarms.world/v1/models/pricing" \
  --data-urlencode "model_name=gpt-5.4" \
  -H "x-api-key: $SWARMS_API_KEY"
```

```json
{
  "status": "success",
  "model_name": "gpt-5.4",
  "input_cost_per_1m": 2.875,
  "output_cost_per_1m": 17.25,
  "price_source": "litellm",
  "timestamp": "2026-10-12T19:01:46.491705+00:00"
}
```

These are example prices at the time of writing; provider prices change, so look them up rather than hard-coding them. Any model name gets a price: `openrouter/...` models are priced from OpenRouter, other models from LiteLLM's price data, and a model with no price data comes back with `"price_source": "fallback"` and the fallback rates plus the fee. `GET /v1/models/available` lists every model with the same `input_cost_per_1m`, `output_cost_per_1m` and `price_source` fields.
