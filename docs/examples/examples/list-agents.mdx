## Step 1 — Get your API key

Create an API key in your dashboard: `https://swarms.world/platform/api-keys`

## Step 2 — Add it to .env

```bash
SWARMS_API_KEY=your-api-key-here
```

## Step 3 — Run the code

<Tabs>
  <Tab title="Python">
    ```python
    import os
    import json
    import requests
    from dotenv import load_dotenv

    load_dotenv()

    BASE_URL = "https://api.swarms.world"
    headers = {
        "x-api-key": os.getenv("SWARMS_API_KEY"),
        "Content-Type": "application/json",
    }

    resp = requests.get(f"{BASE_URL}/v1/agents/list", headers=headers)
    print(resp.status_code)
    data = resp.json()
    print(json.dumps(data, indent=2))
    print(f"Number of agents: {data.get('count')}")
    ```
  </Tab>

## Understanding the Response

`GET /v1/agents/list` returns every unique agent configuration you have used in a prior `agent_config` (from `/v1/agent/completions` or `/v1/agent/batch/completions`), most recently used first. Task-specific fields (`task`, `history`, `img`) are stripped, and each entry carries a `last_used` timestamp:

```json
{
  "success": true,
  "count": 2,
  "agents": [
    {
      "agent_name": "Research Assistant",
      "model_name": "claude-sonnet-5",
      "max_tokens": 16000,
      "system_prompt": "You are a meticulous research assistant.",
      "role": "worker",
      "max_loops": 1,
      "temperature": 0.5,
      "last_used": "2026-09-10T18:22:04.512Z"
    },
    {
      "agent_name": "Document Analyst",
      "model_name": "gpt-4.1",
      "max_tokens": 4096,
      "role": "worker",
      "max_loops": 1,
      "last_used": "2026-09-08T09:15:47.091Z"
    }
  ],
  "timestamp": "2026-09-14T12:00:00.000Z"
}
```

| Field | Type | Description |
|-------|------|--------------|
| `success` | boolean | Whether the request succeeded |
| `count` | integer | Total number of unique agent configurations returned |
| `agents` | array of objects | Each entry is the `agent_config` you previously sent (minus `task`, `history`, `img`), plus `last_used` |
| `timestamp` | string | ISO timestamp when the list was generated |

<Note>
An agent configuration is only listed here after you have run it at least once via `/v1/agent/completions` or `/v1/agent/batch/completions` — agents used only inside a `/v1/swarm/completions` request are not included. Uniqueness is keyed on `agent_name`, so reusing the same name with different settings keeps only the most recent version.
</Note>
